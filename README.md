# JSF C++ Code Style Formatter

## Overview
This repository contains an Uncrustify configuration file designed to enforce consistent code formatting according to JSF (Joint Strike Fighter) C++ coding standards. The configuration carefully balances readability, maintainability, and compliance with industry best practices for safety-critical and embedded systems development.

## Features
- Precise indentation and spacing controls
- Standardized brace placement and newline handling
- Proper template formatting for modern C++
- Pointer and reference notation consistency
- Function declaration and definition formatting

## Purpose
This configuration helps teams maintain a clean, consistent codebase and simplifies code reviews by eliminating discussions about formatting preferences. It's particularly useful for projects requiring strict adherence to coding standards in automotive, aerospace, or other embedded systems domains.
